# 관리자(대표) 사용 설명서

> 1단계 기준. 기능이 추가될 때마다 이 문서도 갱신됩니다.

## 1. 역할과 볼 수 있는 범위

| 역할 | 볼 수 있는 지점 | 할 수 있는 일 (현재) | 앞으로 추가 |
|---|---|---|---|
| **최고관리자(대표)** | 전체 | 계정 발급·수정·중지, 비밀번호 초기화, 변경 이력 조회 | 모든 재무·급여·원가 |
| **본사 관리자** | 대표가 지정한 지점 | 지정 지점 홈 조회 | 매출·구매·재고·업무 관리 |
| **지점 관리자** | 소속 지점만 | 소속 지점 홈 조회 | 매출·일지 입력, 스케줄, 재고·발주, 점검 |
| **일반 직원** | 소속 지점만 | 내 업무 화면 | 출퇴근, 체크리스트, 허용된 재고 입력 |

- 다른 지점 데이터는 **화면뿐 아니라 데이터베이스에서 차단**됩니다. 주소를 직접 입력하거나 프로그램을 조작해도 보이지 않습니다.
- 직원은 손익·다른 직원 급여를 볼 수 없습니다.

## 2. 직원 계정 만들기
1. 왼쪽 메뉴 **관리 → 계정 관리** → **새 계정 만들기**
2. **역할** 선택 (일반 직원 / 지점 관리자 / 본사 관리자)
3. **이름** 입력 → **아이디**에 이름이 자동으로 들어갑니다.
   - 같은 이름의 직원이 이미 있으면 뒤에 숫자를 붙이세요. 예) `김민수2`
4. **비밀번호**
   - 일반 직원: **생년월일 6자리** (예: 1995년 3월 12일생 → `950312`)
   - 관리자: 10자 이상, 영문+숫자
5. **소속 지점** 선택 (대표 외에는 1개 이상 필수)
6. 직원에게 "**이름**으로 로그인하고, 비밀번호는 **생년월일 6자리**"라고 알려주세요.
   - 원하는 직원은 **내 계정 → 비밀번호 변경** 에서 6자리 이상 다른 번호로 바꿀 수 있습니다 (필수 아님).
   - ⚠️ 생일을 아는 동료가 대신 로그인할 수 있습니다. 출퇴근 기록(4단계) 시작 전에 다시 검토하세요.

## 3. 계정 수정 · 퇴사 처리
- 계정 목록의 **수정** 버튼
- 역할·소속 지점 변경 즉시 반영됩니다.
- **퇴사/휴직**: '사용 중' 체크를 해제 → 즉시 로그인과 데이터 접근이 차단됩니다. 기록은 삭제되지 않습니다.
- 본인(대표) 계정은 역할 변경·중지를 할 수 없고, 대표가 1명뿐이면 강등할 수 없습니다.

## 4. 비밀번호를 잊은 경우
계정 관리 → 해당 직원 **수정** → 아래쪽 **비밀번호 초기화** 에 **생년월일 6자리**(관리자는 10자 이상 임시 비밀번호) 입력.
초기화하면 바로 그 비밀번호로 로그인할 수 있습니다.

## 5. 변경 이력
**관리 → 변경 이력** 에서 누가·언제·무엇을 바꿨는지 볼 수 있습니다 (계정·역할·소속·지점 정보).
이력은 대표도 수정·삭제할 수 없습니다.

## 6. 화면 상단 노란 띠
"개발·테스트 환경입니다" 띠가 보이면 **연습용 시스템**입니다. 여기 숫자는 실제 실적이 아닙니다.
실제 운영 사이트에는 이 띠가 없습니다.

## 7. 지점 정보
현재 지점 이름은 `향미옥 1호점/2호점/3호점`, 주소와 좌석수는 **미확인 상태(1호점 9석만 입력)** 입니다.
2단계의 **지점 설정** 화면에서 정확한 주소·좌석수·운영시간을 입력하세요. (좌석당 매출 등 비교 지표에 사용)

## 8. 보안 수칙
- Supabase **Secret key**, 데이터베이스 비밀번호는 대표만 보관.
- 공용 PC에서는 사용 후 반드시 **로그아웃**.
- 퇴사자는 당일 '사용 중' 해제.

## 9. 원가율 (매출 대비 원재료비) · 냉장고 재고 비율
- 거래명세표(외상 포함)를 **지출 입력**에 넣을 때마다 원가율이 바로 바뀝니다.
  보는 곳: **홈** 지점 카드, **거래처 미수** 맨 위, **지출 입력** 합계 아래, **손익**.
- 계산: (이번 달 식재료 매입 − 냉장고 재고) ÷ 이번 달 실매출
  - 냉장고 재고 = 이번 달 매입 × **냉장고 재고 비율**(지점별 5~10%, 처음엔 5%)
  - 예) 매입 1,000만 원, 비율 7% → 70만 원은 냉장고에 남았다고 보고 930만 원만 원가로 계산
- 비율 바꾸기: 위 화면이나 **관리 → 지점 설정**의 **[냉장고 재고 ○% · 바꾸기]** 버튼 → 5~10% 중 선택 → 저장.
  **대표만** 바꿀 수 있고(본사·지점 관리자에게는 버튼이 안 보이고 데이터베이스에서도 막힘), 바꾼 기록은 변경 이력에 남습니다.
- 월말에 남은 재고를 직접 세어 **손익** 화면에 넣은 달(전월 말 + 이달 말 둘 다)은 비율 대신 실제 재고로 계산합니다.
- 오늘 매출은 마감 후에 입력되므로, 낮 동안의 원가율은 어제까지 매출 기준이라 조금 높게 보일 수 있습니다.
